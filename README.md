# MyNetflix: Netflix Landing Page Clone

A responsive clone of the Netflix India landing page, built with **HTML** and **CSS** only. I made it to practise page layout, Flexbox, responsive design and CSS-only interactions.

> **Disclaimer:** This is an educational project and is not affiliated with, endorsed by, or connected to Netflix, Inc. The Netflix name and logo belong to their respective owners.

## Features

- Hero section with a background image, navigation bar, language button and Sign In button
- Email signup form ("Get started") with HTML5 email validation
- Four alternating feature sections (text and image side by side)
- FAQ accordion built with pure CSS (hidden radio inputs and the `:checked` selector, no JavaScript)
- Footer with link columns and a language selector
- Responsive layout with a media query for screens up to 600px
- Dark theme with Netflix-style red accent buttons

## Tech Stack

- HTML5
- CSS3 (Flexbox, media queries, transitions, pseudo-elements)

## How to Run

1. Download the repository as a ZIP (Code → Download ZIP) or clone it with Git.
2. Open the project folder.
3. Double-click `Netflix.html` to open it in your browser. No installation or build step is needed.

- Making a layout responsive using media queries
- Creating an accordion with only CSS
- Styling forms, buttons and a footer to match a real-world design
